# Customer app

Expo (React Native) customer app for Darjeeling Stores. About 38 of 40 screens are built against the real backend (see the status table in PLAN.md). Run it with `npm install` then `npx expo start`; it is a standalone npm project, outside the pnpm workspace.

**Read [PLAN.md](PLAN.md)** for the design direction (fresh quick-commerce look in our maroon / tea-yellow / cream palette),
the technical plan, all 40 screens with their features and backend calls, the delivery phases and the open questions.

Related: [developer 2 plan](../../dev2.md), the API reference in `docs/api/`, and the finished rider app in `apps/rider-app`, whose API layer, theme and UI kit this app reuses.
