# Architecture decisions

Decision records preserve the context and consequences of a choice. Current references describe today's system; historical records should not be the only way to discover current behavior.

| Record | Status | Scope |
| --- | --- | --- |
| [0001: pnpm workspace and modular API](0001-workspace-structure.md) | Implemented, recorded from current source | Workspace packaging and composition |

No prior numbered ADR convention was found. New records use immutable four-digit numbers and descriptive filenames. Use the [decision template](../templates/decision.md), state actual evidence and do not invent historical alternatives or approvals.

Supersede a choice through a new record, link both records, and update the current reference. Preserve the old record instead of editing away the reason it once applied. Existing product choices remain indexed in the [product overview](../00-overview.md); that list is not blanket evidence of implemented integrations.
